## User Issue

A new starter requires an account setup before their first working day.

The user needs access to standard company systems, email, and relevant shared resources based on their department.

## Initial Troubleshooting Note

Confirmed this is a user onboarding request.

Next steps are to:

- Create or verify the user account
- Assign the correct department or role
- Add the user to the required groups
- Confirm email access
- Check shared resource permissions
- Confirm that login details are provided securely

## Possible Root Cause

This is a planned onboarding request rather than a fault. Access may not yet exist because the user account and permissions have not been fully configured.

## Next Support Actions

1. Confirm the new starter’s name and start date.
2. Confirm department and manager.
3. Create or verify the user account.
4. Add the user to the correct security groups.
5. Confirm email account setup.
6. Confirm access to shared resources.
7. Provide login details securely.
8. Update the ticket with completed actions.
