## User Issue

The user reports that their laptop has become very slow when opening applications and switching between windows.

The issue started recently and is affecting their ability to complete normal work tasks.

## Initial Troubleshooting Note

Confirmed this is an endpoint performance issue.

Next steps are to:

- Check Task Manager for high CPU usage
- Check memory usage
- Check disk usage
- Review startup applications
- Confirm available storage space
- Check for pending Windows updates
- Review Event Viewer for recent system errors
- Restart the device if required

## Possible Root Cause

The laptop may be affected by high resource usage, too many startup applications, low disk space, pending updates, or a recent system error.

## Next Support Actions

1. Ask when the issue started.
2. Check whether the issue happens with all applications or only one application.
3. Review Task Manager for CPU, memory, and disk usage.
4. Check available storage.
5. Review startup apps.
6. Check for pending updates.
7. Review Event Viewer logs.
8. Restart the device and test performance again.
9. Escalate if the issue continues.
