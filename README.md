# Service Desk Ticketing System Lab

## Project Overview

This repository documents a hands-on service desk ticketing system lab.

The purpose of this project is to practise common IT Support and Service Desk workflows, including logging incidents, categorising tickets, setting priorities, updating ticket notes, assigning tickets, resolving issues, and writing clear closure notes.

This lab is designed to show practical understanding of how support tickets move from user report to investigation, troubleshooting, resolution, and closure.
