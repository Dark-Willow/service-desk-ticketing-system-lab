# Lab 03 — Creating Support Tickets

## Objective

The objective of this lab is to practise creating different types of service desk tickets in ManageEngine ServiceDesk Plus.

This lab focuses on creating realistic support tickets for common IT Support and Service Desk scenarios.

## Tickets Created

| Ticket | Scenario | Main Area |
|---|---|---|
| Ticket 02 | User unable to log in after password reset | Account access |
| Ticket 03 | User laptop running slowly | Endpoint troubleshooting |
| Ticket 04 | User cannot connect to Wi-Fi | Network connectivity |
| Ticket 05 | New starter needs account setup | User onboarding |

## Ticket 02 — Password Reset Login Issue

This ticket focused on a user who could not log in after a password reset.

The ticket was classified as a high priority account access issue because the user could not access their workstation or company applications.

Troubleshooting steps included checking the username, confirming the password reset, checking whether the account was locked, and asking the user to try the temporary password again.

## Ticket 03 — Slow Laptop Performance

This ticket focused on a user whose laptop was running slowly.

The ticket was classified as a hardware or endpoint performance issue.

Troubleshooting steps included checking Task Manager, CPU usage, memory usage, disk usage, startup applications, storage space, Windows updates, and Event Viewer.

## Ticket 04 — Wi-Fi Connectivity Issue

This ticket focused on a user who could not connect their laptop to Wi-Fi.

The ticket was classified as a network connectivity issue.

Troubleshooting steps included checking whether Wi-Fi was enabled, confirming the correct wireless network, forgetting and reconnecting to the network, restarting the wireless adapter, checking IP configuration, and testing connectivity with ping.

## Ticket 05 — New Starter Account Setup

This ticket focused on a new starter account setup request.

The ticket was classified as a user onboarding request.

Support actions included creating or verifying the user account, assigning the correct department or role, adding the user to required groups, confirming email access, checking shared resource permissions, and providing login details securely.

## What I Learned

This lab helped me practise creating different types of service desk tickets and documenting them clearly.

I learned how different issues require different classification choices, priorities, support groups, and troubleshooting notes.

Account access issues may require higher urgency when the user cannot work. Endpoint performance issues need checks such as Task Manager, storage, startup apps, updates, and Event Viewer. Network issues need connectivity checks such as Wi-Fi settings, adapter status, IP configuration, and ping testing. Onboarding tickets require clear account setup and access permission steps.

This helped me understand how service desk teams document, organise, and manage different types of user support requests.
